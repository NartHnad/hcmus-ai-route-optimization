# hcmus-ai-route-optimization

Lab 1: Search Algorithms for Vietnamese Traffic Route Optimization.

## Feature scope

- Two-location: **Bidirectional Search (weighted UCS/Dijkstra)**.
- Multi-location: **Nearest Neighbor + 2-Opt** remains an independent optimizer.
- Both modes use the existing Map View, Graph View and step-by-step playback.

Technical details: [Bidirectional Search report](docs/report_bidirectional_search.md).
